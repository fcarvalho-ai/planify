- API et frontend servis par un processus Node unique.
- Persistance atomique JSON retenue pour cette RC afin de conserver le démarrage zéro dépendance ; la cible SQLite décrite dans l’architecture reste un chantier avant release stable.
- Le fallback `localStorage` est réservé au mode prototype lorsque l’API est indisponible.

## Commandes de référence

```bash
npm test
npm start
```

Application : `http://localhost:8080` par défaut.
